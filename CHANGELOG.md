# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/), and the project adheres to
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- **Local OCR (opt-in):** scanned PDFs and image uploads (PNG, JPG, JPEG, TIFF, BMP, WEBP) are indexed via RapidOCR — fully local, CPU-only, offline, no CUDA or external binary. Off by default; toggle **Enable OCR** in Settings (`OCR_ENABLED`, requires restart). The PDF parser falls back to OCR only for pages with no text layer; with OCR off, behaviour is unchanged (a scanned PDF still reports no extractable text). Added an `OcrProvider` port so the engine stays replaceable.
- **Upload & indexing progress:** the Documents page shows a per-file progress bar during upload and a progress bar for documents while they are being indexed/converted.
- **Concurrent chats:** each conversation streams independently — the Send button only blocks the conversation currently generating, so new or other chats stay usable while one or more are working.
- **Chat loading indicators:** a minimalist typing indicator in the chat title (and sidebar) and in the message body while an answer streams.
- **Collapsible sources:** chat answers no longer list sources inline; a small "Sources (N)" button reveals them on demand.

### Fixed
- **Follow-up questions kept their subject:** a short follow-up (e.g. "Date of birth" after "Who is Olavo?") now retrieves against the ongoing subject instead of matching unrelated people. Recent conversation turns are sent with the question and used both to anchor retrieval and to ground generation.

## [0.1.0] - 2026-10-27

### Added
- **Phase 1 — Foundation:** monorepo, FastAPI backend (Clean Architecture), React/Vite/Tailwind frontend, validated settings, health endpoints, CI, and Windows scripts.
- **Phase 2 — Domain & storage:** domain entities and lifecycle, repository ports, embedded ChromaDB chunk + document-registry repositories, path-safe filesystem storage, and atomic JSON indexing-job store.
- **Phase 3 — Document upload:** validation (type/size/signature/UTF-8), SHA-256 duplicate detection, and upload/list/get/download/delete endpoints.
- **Phase 4 — Ingestion:** PDF/DOCX/TXT/MD parsers, chunking with overlap and page numbers, Ollama embedding adapter, all-or-nothing index use case, and an in-process background indexing worker with job tracking, retry, and restart recovery; content/reindex/indexing-jobs endpoints.
- **Phase 5 — Semantic search:** LLM-free `POST /api/v1/search/semantic`, scoped to indexed documents.
- **Phase 6 — RAG chat:** grounded `POST /api/v1/chat` and streaming `POST /api/v1/chat/stream` (retrieval → bounded context → prompt → local Ollama generation), with real (non-fabricated) source citations, a `grounded` flag, prompt-injection-safe grounding, and `GET /api/v1/models` + `/models/status`.
- **Phase 7 — Frontend:** React app wired to the API — Dashboard (live stats + infra/model status), Documents (drag-and-drop upload, table, preview/download/reindex/delete, auto-refresh while indexing), Search, streaming AI Chat with sources, and read-only Settings. Plus backend `GET /dashboard/stats` and `GET /settings`.
- **Settings:** `PATCH /api/v1/settings` persists validated overrides to `config_dir/overrides.json`, applied on restart, with `requires_restart`/`requires_reindex` flags and an embedding-model reindex warning (ADR-0008).
- **API spec:** committed `backend/openapi.json` (importable into Insomnia/Postman), generated by `scripts/export_openapi.py` and kept current by a contract test.
- **Governance:** adopted the AI-Dash management layer (ADRs under `docs/adr/`, `docs/decisions.md`, `docs/tasks.md`, `docs/repo-map.md`, `AGENT_TEAM.md`, guides) — see ADR-0005.

- **Phase 8 — Testing & quality:** architecture-boundary test enforcing Clean Architecture, an end-to-end restart/persistence test, opt-in live-Ollama verification tests, and a `conftest.py` that keeps the ChromaDB-heavy suite deterministic. Coverage: domain 98%, application 97%, 96% total.
- **Phase 9 — Documentation & delivery:** architecture overview, API reference, Windows deployment guide, and the final implementation report; README/ROADMAP updated to "complete".
- **Frontend UX:** responsive layout with a collapsible mobile sidebar; light/dark/system theme toggle in Settings (persisted); an editable Settings form wired to `PATCH /settings` with restart/reindex indicators; and persistent AI chat — conversations are stored and listed, and streaming continues across navigation.
- **Agent & CI hardening:** an `agent-test` post-push verification agent and a `pre-push` gate; CI aligned to Node 24 / npm 11 with deprecation-free actions.

### Notes
- Real Ollama embedding (`embeddinggemma`) and generation (`qwen3:0.6b`) are verified by opt-in live tests that skip when Ollama is unavailable; the default suite remains offline/CI-safe with mocks and fakes.
